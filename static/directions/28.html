Hi, I’m Raygen.

It’s easy to introduce myself with a machine. There’s something to point at: a frame, a motor, a thing that moves. But there’s more of me in the work than the finished object.

There’s the code that makes it useful. The person learning a tool for the first time. The project that needs another pair of eyes. I care about those parts, too.

I’m still a student. Still making things, still figuring things out, and happy to be around people doing the same.

Thanks for looking around.
