## Social preview

`static/social-card.svg` and `static/social-card.png` are generated by
`scripts/generate-social-card.mjs`. They use the unmodified Serv0 assembly render
attributed above, alongside Raygen's supplied biographical information. The SVG
embeds the original assembly image and includes provenance metadata; the PNG has
the same provenance in an Impeccable-compatible `impeccable:prompt` PNG text chunk,
verified using Impeccable's `embed-prompt --read` command. Regeneration preserves
this metadata. The card
uses Archivo and Manrope from Google Fonts; their Open Font License files are in
`static/fonts/`. The source render retains its CC BY-NC-SA 4.0 license.

## Lossless production image variants

On September 20, 2026, the seven PNG images used on the production homepage were
also encoded as same-name `.webp` files beside their originals. Pillow 12.3.0
used libwebp lossless encoding with `exact=True`, retaining the original size and
all RGBA pixel values, including RGB values beneath fully transparent pixels.
Every decoded WebP was compared byte for byte with its source decoded as RGBA;
all seven matched. No cropping, resizing, recoloring, or generated artwork was
involved. The original PNG files remain available and the original attribution
and reuse restrictions above apply equally to their WebP variants.

Each WebP includes verified embedded XMP containing its original source URL,
creator attribution, source PNG SHA-256, conversion description, and the source
license link where one was documented above. This conversion creates no new
permission to reuse the artwork.

| Production variant | Original PNG bytes | Lossless WebP bytes | Reduction |
| --- | ---: | ---: | ---: |
| `serv0.webp` | 2,207,652 | 751,468 | 66.0% |
| `serv0-open.webp` | 2,824,632 | 906,484 | 67.9% |
| `david.webp` | 502,243 | 324,662 | 35.4% |
| `monstrosity.webp` | 2,188,325 | 1,416,660 | 35.3% |
| `raygen.webp` | 67,678 | 47,436 | 29.9% |
| `../brand/stardance-logo.webp` | 290,823 | 187,132 | 35.7% |
| `../brand/outpost-logo.webp` | 55,873 | 19,640 | 64.8% |

The seven unique homepage images total **8,137,226 bytes → 3,653,482 bytes**,
a **55.1% reduction**, with unchanged dimensions and pixels.
